# Laajennosluonnos (EI TESTATTU SELAIMESSA)

Minimalinen MV3-luonnos testatun native-isännän ympärille: klikkaus
lähettää valitun tekstin isännälle ja tulostaa löydökset konsoliin.
Puuttuu: inline-korostukset sivuun, kenttäintegraatio (input/textarea/
contenteditable), asetukset, Firefox/Chrome-paketointi, loppukäyttäjän
asennusohje. Edellyttää isäntämanifestin rekisteröinnin (käyttäjän
hyväksynnällä - ks. ../README.md ja docs/threat-model.md).
